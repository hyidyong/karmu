# Karmu 온보딩·액션·지도 필터 확장 설계

## 목적

발표용 모바일 웹앱에서 사용자가 학교와 역할을 고른 뒤 바로 앱을 시작하고, 모든 액션 요소가 실제 화면 이동이나 상태 변경으로 이어지게 한다. 지도에서는 학생·교직원 주차장과 가까운 주차장, 충전소, 주유소를 빠르게 필터링한다. 계명대학교 성서캠퍼스는 전체 기능을 시연할 수 있는 주 테넌트로 제공하고, 다른 대학도 같은 구조에서 간단한 샘플 데이터를 조회할 수 있게 한다.

## 결정 사항

- Supabase는 연결하지 않는다. 민감 정보나 실제 사용자 계정이 없는 발표용 데모이므로 브라우저 저장 상태만 사용한다.
- 배포는 Vercel을 우선 사용한다. 배포 환경 변수에는 기존 Google Maps/Routes 설정만 등록한다.
- 학교와 역할 선택은 인증이 아닌 데모 세션이다. 학교 선택과 `학생 | 교직원` 선택만 요구한다.
- 모든 대학 데이터는 `universityId`, `campusId`, `parkingLotId`로 분리한다.
- 새 UI는 기존 계명대 파란색, 적색 위험 강조, 테두리 없는 채움형 버튼, 공통 `1rem` 모서리를 유지한다.

## 사용자 흐름

1. 첫 접속 시 `/welcome`에서 학교를 선택한다.
2. 사용자는 `학생` 또는 `교직원`을 선택하고 `Karmu 시작하기`를 누른다.
3. 선택값을 버전이 있는 로컬 세션으로 저장하고 해당 대학 홈으로 이동한다.
4. 학생은 `안녕하세요, 김학생님`, 교직원은 `안녕하세요, 김교직원님` 인사를 본다.
5. 헤더의 대학명을 누르면 온보딩으로 돌아가 학교와 역할을 바꿀 수 있다.
6. 알림 아이콘을 누르면 알림 목록으로 이동한다.
7. 지도에서 카테고리를 누르면 지도 마커와 하단 목록이 함께 갱신된다.
8. 주차장 상세의 길찾기 버튼은 선택 주차장 좌표로 Google 지도 앱 또는 웹을 연다.

## 데모 세션과 테넌트 상태

세션은 실제 인증 토큰이 아닌 다음 값만 가진다.

```ts
type DemoSession = {
  version: 1;
  universityId: string;
  campusId: string;
  role: "student" | "staff";
};
```

온보딩 완료 시 동일한 비민감 선택값을 `localStorage`와 쿠키에 저장한다. `localStorage`는 클라이언트 상호작용과 알림 읽음 상태에 사용하고, 쿠키는 Next.js Server Component가 첫 렌더부터 올바른 대학 데이터를 고르는 데 사용한다. 세션이 없거나 유효하지 않으면 학생 영역에서 `/welcome`로 이동한다. 로그아웃 대신 `학교·역할 변경` 액션을 제공하고 기존 선택값을 바꾼다.

쿠키와 저장값은 대학 또는 역할 목록에 존재하는 값만 허용한다. 인증·인가 용도로 사용하지 않으며 관리자 기능은 노출하지 않는다.

## 대학별 데모 데이터

### 계명대학교 성서캠퍼스

기존 건물 10곳 이상, 주차장 8곳 이상, 동문·남문 학생주차장, 시간대별 혼잡도와 목적지별 접근 데이터를 그대로 사용한다. 충전소와 주유소 샘플을 각각 여러 곳 추가한다.

### 다른 대학

온보딩 목록에는 최소 다음 대학을 보여준다.

- 계명대학교 성서캠퍼스 — 전체 데모
- 경북대학교 대구캠퍼스 — 간단 샘플
- 영남대학교 경산캠퍼스 — 간단 샘플

경북대학교와 영남대학교는 학교별 브랜드, 기본 목적지 1~2곳, 주차장 2~3곳을 제공한다. 실제 운영 데이터처럼 오인되지 않도록 앱 하단이나 데이터 설명에 데모 데이터임을 표시한다. 추천·지도·상세 경로는 같은 저장소 계약으로 동작한다.

## 온보딩 화면

- 첫 화면 제목은 `학교를 선택하세요`로 짧게 쓴다.
- 검색 입력으로 대학 이름과 캠퍼스를 필터링한다.
- 대학 선택 목록은 한 번에 이해되는 단순 행 구조로 만든다.
- 역할은 `학생`, `교직원` 두 개의 채움형 세그먼트 버튼으로 제공한다.
- 학교와 역할이 모두 선택돼야 시작 버튼이 활성화된다.
- 별도 학번, 비밀번호, 소셜 로그인은 만들지 않는다.
- PWA로 설치한 뒤에도 선택 상태를 유지한다.

## 지도 필터

지도 페이지의 긴 제목과 설명을 제거하고 주 제목을 `근처 주차장 찾기`로 바꾼다. 지도 바로 위에 가로 스크롤 가능한 한 줄 카테고리 바를 둔다.

카테고리는 다음 여섯 개다.

- 전체
- 학생
- 교직원
- 가까운 주차장
- 충전소
- 주유소

선택된 항목은 계명대 파란색 배경과 흰색 아이콘·텍스트, 선택되지 않은 항목은 연한 회색 표면을 사용한다. 테두리는 넣지 않는다. 각 항목은 아이콘과 짧은 텍스트를 함께 사용하고 최소 44px 터치 영역을 지킨다.

`학생`은 `student` 주차장, `교직원`은 `staff` 주차장을 표시한다. `전체`에는 `shared`를 포함한 모든 주차장을 표시한다. `가까운 주차장`은 현재 위치를 요청해 거리순으로 정렬하고, 권한 거절 또는 시간 초과 시 선택한 캠퍼스 중심을 기준으로 정렬한다. `충전소`와 `주유소`는 별도 시설 타입과 마커를 표시한다.

발표 안정성을 위해 시설은 테넌트별 mock repository에서 제공한다. Google Places를 활성화한 후 같은 repository 계약으로 실제 검색 구현을 교체할 수 있게 하되 이번 배포의 필수 조건으로 삼지 않는다.

필터 변경 시 다음이 함께 바뀐다.

- 지도 마커
- 결과 개수
- 지도 아래 목록 제목과 항목
- 선택된 마커 상태
- 결과가 없을 때의 간단한 빈 상태

## 액션 동작

### 홈과 추천

- 목적지 행은 추천 화면으로 이동한다.
- `현재 위치에서 지금 출발`은 위치 확인, ETA 계산, 결과 이동 상태를 보여주고 중복 클릭을 막는다.
- 홈 `지금 캠퍼스 주차`의 추천 아이콘은 `Sparkles` 대신 전구 아이콘을 사용한다.
- 추천 카드와 상세 정보 버튼은 도착 시각과 목적지 쿼리를 유지한다.

### 알림

헤더 알림 아이콘은 `/notifications`로 이동한다. 기본 알림은 다음 유형을 포함한다.

- 정기 주차권 신청 기간 안내
- 주차 요금 인상 안내
- 행사 또는 공사에 따른 주차장 운영 변경

알림은 읽음·안 읽음 상태를 시각적으로 구분한다. 개별 알림을 열면 상세 내용을 펼치고 읽음 처리하며, `모두 읽음` 액션도 제공한다. 읽음 상태는 대학별로 `localStorage`에 저장한다. 알림 배지는 읽지 않은 개수와 동기화한다.

### 차량과 정기권

- 차량 카드는 등록 차량 상세를 열 수 있다.
- 정기권 카드는 신청 기간, 유효 기간, 필요서류 상세를 열 수 있다.
- 데모용 관리 액션은 저장 가능한 로컬 상태와 성공 피드백을 제공한다.
- 실제 신청 제출이나 결제처럼 서버가 필요한 동작은 수행한 척하지 않고 `데모 신청이 저장됐어요`라고 명확히 표시한다.

### 지도와 길찾기

- 지도 마커 선택은 같은 항목을 하단 목록에서 강조한다.
- 주차장 목록과 상세 정보 액션은 실제 상세 경로로 이동한다.
- 상세 CTA는 Google Maps Directions URL을 새 창으로 열어 해당 좌표까지 길찾기를 시작한다.
- 팝업 차단이나 외부 앱 실행 실패를 피하기 위해 표준 HTTPS 지도 URL을 사용한다.

## 상태와 피드백

- 로딩 중인 버튼은 아이콘과 문구를 바꾸고 중복 입력을 막는다.
- 성공 상태는 짧은 인라인 메시지 또는 토스트로 알린다.
- 오류 상태는 원인과 다시 시도 액션을 제공한다.
- 다이얼로그나 시트는 포커스를 가두고 `Esc`, 바깥 영역, 닫기 버튼으로 종료할 수 있게 한다.
- 페이지 이동 링크와 상태 변경 버튼의 역할을 구분한다.
- 모든 인터랙션은 키보드와 스크린리더 이름을 제공한다.

## 성능

- Google 지도 모듈은 기존처럼 동적 로딩한다.
- 시설 mock 데이터와 필터 로직은 작은 정적 모듈로 분리한다.
- 대형 상태 관리 라이브러리나 추가 인증 SDK를 도입하지 않는다.
- 클라이언트 컴포넌트는 온보딩, 지도 필터, 알림, 관리 시트 등 실제 상호작용 경계에만 둔다.
- 서버 페이지는 선택된 테넌트 데이터만 직렬화한다.

## 오류 처리

- 잘못된 저장 세션: `/welcome`로 이동
- 위치 권한 거절·시간 초과: 캠퍼스 중심 거리순으로 자동 전환하고 안내
- 선택 대학의 데이터 없음: 간단한 준비 중 상태와 학교 변경 액션
- Google 지도 로딩 실패: 필터 가능한 목록 폴백 유지
- 알림 저장소 접근 실패: 현재 탭에서만 상태 유지
- Google 길찾기 팝업 차단: 같은 탭에서 표준 지도 URL로 이동 가능한 링크 유지

## 테스트

테스트 우선으로 다음 동작을 검증한다.

- 세션 직렬화·파싱과 잘못된 값 거부
- 역할별 인사말과 이용 가능한 주차장 필터
- 대학별 repository 격리
- 지도 여섯 카테고리의 필터 결과와 가까운 순 정렬
- 위치 실패 시 캠퍼스 중심 폴백
- 알림 읽음 상태와 읽지 않은 개수 계산
- Google 길찾기 URL 생성
- 온보딩에서 학교·역할 선택 후 홈 진입
- 학생·교직원 전환 후 인사말과 지도 결과 변경
- 알림 진입, 개별 읽음, 모두 읽음
- 지도 필터, 마커, 목록, 상세, 외부 길찾기 흐름
- 320·375·390·430·480px에서 가로 넘침과 하단 내비게이션 충돌 없음
- 타입 검사, 린트, 단위 테스트, 프로덕션 빌드 통과

## 배포

GitHub `hyidyong/karmu`의 `main` 브랜치에 단계별 커밋을 푸시한 뒤 Vercel 프로덕션 배포를 만든다. Vercel 인증과 프로젝트 생성 권한이 현재 환경에 있으면 실제 공개 URL까지 제공한다. Google Maps/Routes 환경 변수를 Vercel 프로젝트에 등록하되 실제 값은 Git에 커밋하지 않는다.

Supabase는 이번 배포에 필요하지 않다. 이후 실제 계정, 서버 간 데이터 동기화, 차량·정기권 신청 쓰기 기능을 도입할 때 repository 구현과 데모 세션을 Supabase Auth/Postgres로 교체한다.

## 완료 조건

- 첫 접속에서 학교와 역할을 선택해 홈에 진입한다.
- 새로고침과 PWA 재실행 후에도 선택 상태가 유지된다.
- 계명대 학생과 교직원 인사말과 주차장 범위가 역할에 맞게 달라진다.
- 경북대와 영남대 선택 시 최소 샘플 주차 데이터를 탐색할 수 있다.
- 알림 화면에 정기권 신청 기간과 요금 인상 안내가 표시되고 읽음 처리가 동작한다.
- 지도 여섯 필터가 마커와 목록을 실제로 변경한다.
- 홈 추천 아이콘이 전구로 표시된다.
- 모든 액션 버튼이 이동, 상태 변경, 외부 길찾기 중 하나의 명확한 결과를 만든다.
- 모바일 자동 레이아웃, 테스트, 빌드, 브라우저 핵심 흐름 검증이 통과한다.
- 공개 배포가 성공하면 최종 URL을 사용자에게 제공한다.
